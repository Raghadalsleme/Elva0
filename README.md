# ثيم ELVA لسلة

ثيم لدار أزياء ELVA مبني على **ثيم رائد** (نقطة البداية الرسمية من سلة لمحرك Twilight).

## الهوية

| اللون | الكود | الاستخدام |
|---|---|---|
| برقوقي | `#4B1D3F` | اللون الأساسي، الأزرار، الشريط العلوي، الفوتر |
| كريمي | `#E7DAC0` | النصوص على البرقوقي، الخلفية الفاتحة `#FAF6EE` |
| وردي هادئ | `#D8A7B1` | الزخارف، الإطارات، الشارات |

- **خط العناوين:** Cormorant Garamond للإنجليزي (قريب من خط الشعار) و El Messiri للعربي.
- **خط النصوص:** خط المتجر اللي يختاره التاجر من إعدادات سلة.
- **الزخارف:** الإطار المزدوج، وخط النقطتين، وخط المعيّن ◆ مأخوذة من الشعار نفسه.

## اللي تغيّر عن رائد

- `src/assets/styles/04-components/elva.scss`: طبقة الهوية كاملة (ألوان، خطوط، الهيدر، بطاقات المنتجات، الفوتر، والعناصر الجديدة).
- `src/views/layouts/master.twig`: تحميل الخطوط ولوحة ألوان ELVA.
- `tailwind.config.js`: ألوان `elva-*` وخط `font-display`.
- `twilight.json`: اسم الثيم، إعداد "لوحة ألوان المتجر"، وأربع عناصر جديدة للرئيسية:

| العنصر | الملف | الوصف |
|---|---|---|
| واجهة ELVA الرئيسية | `home/elva-hero.twig` | بنر بإطار مزدوج مثل الشعار، يشتغل بصورة أو بدونها |
| مجموعات ELVA | `home/elva-collections.twig` | بطاقات طولية للتصنيفات، الإطار يظهر عند المرور |
| قصة ELVA | `home/elva-story.twig` | صورة بإطار جانبي ونص تعريفي، بخلفية برقوقية أو فاتحة |
| وعود ELVA | `home/elva-promises.twig` | شريط برقوقي (توصيل، تغليف، جودة، خدمة) |

عناصر رائد الأصلية باقية وتقدر تضيفها من محرر الرئيسية.

## رفع الثيم على سلة

1. أنشئ مستودع جديد فاضي في GitHub (مثلاً `elva-theme`) وارفع هذا المجلد عليه:
   ```
   git init
   git add .
   git commit -m "ELVA theme"
   git branch -M main
   git remote add origin https://github.com/USERNAME/elva-theme.git
   git push -u origin main
   ```
2. ثبّت أداة سلة وسجّل دخول:
   ```
   npm install -g @salla.sa/cli
   salla login
   ```
3. أنشئ الثيم واختر **استيراد ثيم من GitHub** واختر المستودع:
   ```
   salla theme create
   ```
   (أو من بوابة شركاء سلة: الثيمات ← إنشاء ثيم ← استيراد ثيم.)
4. للمعاينة على متجرك التجريبي، من داخل المجلد:
   ```
   pnpm install
   salla theme preview
   ```

## قبل النشر

- في `twilight.json` عدّل `repository` لرابط مستودعك، و `support_url` لرابط الدعم حقك، وتأكد من `author_email`.
- أزرار الواجهة والقصة ما تظهر إلا إذا حددت لها رابط من المحرر.
- أضف صور معاينة للعناصر الأربعة (حقل `image` لكل عنصر في `twilight.json`) وصور الثيم المطلوبة للنشر.
